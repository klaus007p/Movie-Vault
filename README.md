# 🎬 Movie Explorer

A modern and responsive movie discovery web application built with **React**. Explore popular and trending movies, search for your favorite titles, and discover your next movie to watch through a clean and interactive interface.

## ✨ Features

* 🎬 Browse popular and trending movies
* 🔍 Search for movies
* 📄 View detailed movie information
* ❤️ Save and manage favorite movies
* 📱 Fully responsive design
* ⚡ Fast and smooth React-based UI
* 🎨 Modern interface with animations
* ☁️ Appwrite integration for backend functionality
* 🧩 Reusable and modular React components

## 🛠️ Tech Stack

* **React** – Frontend library
* **React Router** – Client-side routing
* **Tailwind CSS** – Styling and responsive design
* **Appwrite** – Backend and data storage
* **Framer Motion** – Animations and transitions
* **Lucide React** – Icons
* **JavaScript (ES6+)** – Application logic
* **Vite** – Development and build tool

## 📂 Project Structure

```text
src/
├── appwrite/       # Appwrite configuration and services
├── assets/         # Images and static assets
├── components/     # Reusable UI components
├── contexts/       # React Context providers
├── hooks/          # Custom React hooks
├── pages/          # Application pages
├── search/         # Search-related functionality
├── movies/         # Movie-related functionality
├── App.jsx         # Main application component
├── main.jsx        # Application entry point
├── index.css       # Global styles

```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### 2. Navigate to the project

```bash
cd your-repository-name
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory and add your required API and Appwrite credentials:

```env
VITE_API_KEY=your_api_key
VITE_APPWRITE_ENDPOINT=your_appwrite_endpoint
VITE_APPWRITE_PROJECT_ID=your_project_id
```

> ⚠️ Never commit your `.env` file or expose private API keys in your repository.

### 5. Start the development server

```bash
npm run dev
```

Open the local development URL provided by Vite in your browser.
